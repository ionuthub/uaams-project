# GitHub Project Board

GitHub Projects could not be created through the available automated tools in this workspace, so create a GitHub Project manually with these columns:

```text
Backlog
To do
In progress
In review
Blocked
Done
```

Every task must have:

- Owner.
- Done-when line.
- Evidence required.
- Report section affected.

Use the project board to track Sprint 2 work from backlog through review and completion. Move blocked work to `Blocked` and add a blocker issue when a decision is needed.
